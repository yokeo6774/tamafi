# Support

Use GitHub issues for reproducible bugs, hardware bring-up reports, and feature
requests.

Before opening an issue, include:

- board name,
- port used for upload,
- exact build command,
- ESP32 Arduino core version,
- library versions,
- what works and what does not work,
- photo or short video when the problem is visual.

For board-porting work, start with `docs/tamafi-porting-manual.md`.
