# Code Of Conduct

This project should stay useful, direct, and friendly.

## Expected Behavior

- Be respectful and specific.
- Assume hardware bring-up can fail for boring reasons before blaming people.
- Share enough detail for someone else to reproduce the issue.
- Keep discussions focused on the firmware, documentation, and supported boards.

## Unacceptable Behavior

- Harassment, insults, threats, or personal attacks.
- Posting private information without permission.
- Repeated low-effort demands without diagnostics or context.
- Security reports posted publicly before a fix is available.

## Enforcement

Maintainers may edit, hide, close, or remove comments, issues, pull requests, or
access when behavior makes the project harder to maintain.
